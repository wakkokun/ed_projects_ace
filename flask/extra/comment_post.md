# Comment Post
On each post container, there should be a button with the text "Comment" which shows an overlay with the following content:
* A background that fits the content
* A text area that will be the content of the comment
* A header with the text "Commenting to $USER post" replacing "$USER" with the actual original poster username
* A button to cancel commenting that closes comment container and earses its content
* A button that posts the comment under the post as a dropdown text container
* The dropdown text container should have the comments listed with the comment autor as a header and the parafrag of the comment bellow
* The dropdown container for comments should have a tree structure
